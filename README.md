# 毛泽东选集阅读器

把四卷《毛泽东选集》放进手机，按目录慢慢读。读到一半随时离开，下次打开还能接着上次的位置；遇到值得记下的文字，选中它就能写笔记。

这是一款面向安卓手机的离线阅读器，收录四卷 **159 篇文章**。界面围绕阅读、续读和记录设计，不需要注册账号，也不依赖云服务。

## 功能

### 按卷目录阅读

按第一卷至第四卷浏览文章目录，直接打开想读的文章。每卷会显示文章数量和阅读进度，方便了解读到哪里。

### 从上次位置继续

书架首页会显示最近阅读的文章和进度。点“续读”即可回到上次阅读的位置，不必重新查找。

### 选中文字，随手记笔记

在文章中长按并选择任意文字，点“记笔记”即可为这段摘录添加自己的想法。笔记页支持检索和编辑笔记，也能跳回原文摘录的位置。

### 书签与文章注释

用书签留住想重读的内容。文章中的注释角标对应文末注释，点角标即可查看说明。

### 离线阅读，数据保存在本机

文章内容随 App 一起安装，可离线阅读。阅读进度、书签和笔记都保存在手机本地；没有账号或云同步，卸载 App 会删除这些数据。此 APK 不申请网络权限。

### 暗色阅读界面

使用暗色主题与适合长时间阅读的文字排版，尽量让目录和正文保持清晰。

## 本地构建

需要 Node.js、pnpm、JDK 21 和 Android SDK 36：

```powershell
pnpm install --frozen-lockfile
.\build-apk.ps1
```

脚本读取 `JAVA_HOME`、`ANDROID_SDK_ROOT`（或 `ANDROID_HOME`）中的本地工具链；在 Codex 工作区中也会自动使用附带的便携 JDK/SDK。APK 输出到项目根目录。
